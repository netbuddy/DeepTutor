# 使用手册

`index.html` 是给使用者看的操作手册，可以直接用浏览器打开，也可以放到任意静态文件服务上分发。
它是自包含的单文件——17 张截图以 base64 内嵌在里面，不依赖任何外部资源。

## 目录里的东西

| 文件 | 是什么 |
|---|---|
| `index.html` | **完整 HTML 文档**，自带 `<meta charset="utf-8">`。放静态服务上用这一份 |
| `artifact.html` | 同样的内容，但只是页面片段（没有 head）。发布成在线页面时用它 |
| `模板.html` | 源文件。图片位置写成 `{{IMG:文件名｜图说}}` 形式的占位符 |
| `img/*.webp` | 压缩后的截图，17 张共 580 KB |
| `build.py` | 把占位符换成内嵌图片，同时生成上面两份成品 |

**为什么要两份**：Python 自带的 `http.server` 返回的 `Content-Type` 不带字符集，
页面里再没有 charset 声明的话，浏览器会按自己的默认编码去解析 UTF-8 字节，
整页中文全变乱码。所以静态服务必须用带 head 的那一份。在线发布平台会自己套一层
带 charset 的外壳，用片段版即可。

## 改了内容怎么重新生成

改 `模板.html`，然后：

```bash
cd ~/DeepTutor-ext/docs/manual && python3 build.py
```

## 换截图

界面改了就重新截图，存成 `img/<原文件名>.webp`，再跑一次 `build.py`。

截图统一用 **1280×577** 的视口，这样手册里所有图宽度一致。采集时用的是
`agent-browser --args "--no-sandbox"`，压缩用 Pillow 存 WEBP、质量 76。
