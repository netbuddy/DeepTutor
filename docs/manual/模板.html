1这是什么

DeepTutor 是一个「会陪你学」的软件。你可以把它当成三样东西合在一起：

  • 一个能问的助教——随时提问，它用中文回答；
  • 一个能读的课本——网上的公开课导进来，按章节排好给你看；
  • 一个能跑代码的练习本——课本里的每段代码旁边都有「运行」按钮，点一下就出结果，图表也直接画在页面上。

最后一条是关键。学编程类的课，光看代码没用，得自己跑一遍、改一改再跑，才知道每行在干什么。 以前这需要你在自己电脑上装一堆环境；现在什么都不用装，代码跑在服务器上， 你只要点按钮。

3先随便问一句，感受一下

还没导课程之前，可以先在主页直接提问，就像用别的聊天工具一样。

{{IMG:17-首页提问|在中间的框里输入问题，按回车发送。下方那一排可以选它用哪个资料库、哪个模型。}}
  1. 在中间的框里打字比如输入「什么是过拟合？用一个生活里的比喻说明。」
  2. 按回车发送回答会一个字一个字地出现，通常几秒到几十秒。
  3. 接着追问它记得上文，可以直接说「再举个例子」。

输入框下面那排小控件里，「知识库」决定它回答时去查哪些资料。 默认不选就是凭它自己知道的回答；选上某个资料库，它会先去查再答，答案会更贴课程内容。 第 8 节会讲这个。

4导入一门课

这是这套软件最有用的功能：把网上的公开课整个搬进来。搬进来之后，讲义变成能读的课本， 课里的代码变成能点着跑的练习。

点左边的「课程」：

{{IMG:02-课程页|课程页。上半部分是新增课程的表单，下半部分是已经导进来的课。}}

要填什么

{{IMG:03-新增课程表单|填好的样子。只有第一行是必填的。}}
  1. 课程来源 填一个 GitHub 仓库地址，也就是那门课源文件存放的位置，比如 https://github.com/huggingface/course.git。 怎么找：在浏览器里打开那门课的 GitHub 页面，把地址栏里的网址后面加上 .git 就是了。
  2. 课程名称 留空的话会用课程自己写的标题。想显示成中文名就自己填一个。
  3. 优先用哪种语言的正文 很多公开课有多语言版本。选「中文」，有中文版就用中文版，没有就自动退回英文版。
  4. 顺带建检索索引 勾上的话，导入时会把整门课的正文做成一份可检索的资料库，助教答题时能翻遍整门课、 告诉你「这个在第几章讲过」。建议勾上，代价是导入会慢几分钟。 不勾也能随时补建。
  5. 已存在同名课程时覆盖 同一门课重新导一次（比如课程更新了）才需要勾。
  6. 点「取课程」 小的课几秒就好，大的课（带很多图片的）可能要几分钟。页面上会有提示。
导入要花多久

主要看那门课的仓库有多大。Hugging Face 那门课 25 MB，五秒就导完了； 微软那门机器学习课带了大量图片和几十种语言的翻译，1.8 GB，要等几分钟。 勾了「建检索索引」的话，再加几分钟。

导完之后

{{IMG:04-课程卡片|每门课一张卡片，写着它有多少章多少页、多少段代码能跑、索引建没建。}}

卡片上的几个数字是什么意思：

写着意思
章节 12 章 78 页这门课被拆成了 12 章、78 个页面。一页大致对应原课程的一节。
可运行代码段 128有 128 段代码是可以点「运行」的。
占用 24.6 MB课程文件在服务器上占的空间。
检索索引 course-…已经建好了，后面跟着建好的时间。写「未建」就是还没建。
目录树配正文 / 讲义配 notebook这门课原本是怎么组织的。不用管，系统自己认。

如果导入时跳过了一些文件（有些课程里混着损坏的文件），卡片上会写明跳过了几个， 不影响其余内容。

5在课本里学

课程卡片上点「打开课本」，或者从左边的「书籍」进去：

{{IMG:05-书架|书架。每门导进来的课都是这里的一本书。}}

点进一本书，界面分三块：

{{IMG:06-课本讲义|左边是章节目录，中间是正文，右边是这一页的小节导航。}}
  • 左边是这门课的章节。点一章展开，点一节跳过去。
  • 中间是正文。讲义按小节切开了，一段一段读。
  • 右边是这一页里都有哪些小块，点一下直接跳到那里。页数多的时候很有用。

正文里的图片、公式、表格都会正常显示。你可以像读网页一样往下滚。

6把代码跑起来

往下滚，遇到代码的地方长这样——注意右上角那一排按钮，这是普通网页课程没有的：

{{IMG:07-可运行单元格|一段可运行的代码。左上角「第 1 格」是它的编号，右上角四个按钮。}}

四个按钮

按钮做什么什么时候用
运行 只跑这一段。 从上往下顺着学的时候用这个。
从头跑到这 先把这一页前面的代码依次跑一遍，再跑这一段。 跳着看的时候用这个。后面的代码常常要用前面算出来的东西，直接跑会报错。
重置 把这一页已经算出来的东西全部清空，从干净的状态重新开始。 改了很多东西想推倒重来的时候。
问助教 把这段代码和它的运行结果一起发给助教提问。 看不懂、跑不通的时候。第 8 节细讲。

点一下「运行」

{{IMG:08-运行结果|运行完了。「输出」下面是这段代码算出来的结果，前面那行小字写着用了多久。}}

第一次运行某些代码会比较慢（几十秒），因为服务器要去下载它需要的模型文件； 同样的代码第二次跑就快了。

输出有三种样子

一是文字，就像上面那张图。

二是表格，处理数据的课里很常见：

{{IMG:10-表格输出|表格会排整齐显示。这一格前面还有小字提示「先跑了前面 1 格」，说明用的是「从头跑到这」。}}

三是图表，直接画在页面上：

{{IMG:09-图表输出|散点图。这张图是刚刚在服务器上画出来的，不是课程里的截图。}}
一个重要的概念：这一页是「连着的」

同一页里的代码共享同一份计算状态。第 1 格读进来的数据，第 5 格能直接用； 第 5 格算出来的结果，第 10 格还认得。这就是为什么跳着跑会报错—— 后面的代码要用前面的东西，而前面那些你还没跑。

换一页（换一节课）就是全新的开始，两页之间互不影响。

改代码再跑

代码框是可以直接改的。把光标点进去，像编辑文本一样改，改完点「运行」跑的就是你改后的版本。 改过之后编号旁边会出现一个「已修改」的标记，还会多一个「还原」按钮， 点它就回到课程原本的写法。

这是学编程最有效的方式：把某个数字改大改小、把某一行删掉，看看结果怎么变。 改坏了也不要紧，还原一下就行，不会影响课程本身。

7跑错了怎么办

报错很正常，尤其是跳着跑的时候。报错长这样：

{{IMG:11-报错提示|红色区域是报错信息，最下面一行是给你的建议。}}

红色区域从上到下：

  1. 第一行是错误类型和一句话说明比如 NameError: name 'new_pumpkins' is not defined，意思是「你用了一个还不存在的东西」。
  2. 中间是详细的追踪信息看不懂可以跳过，它主要给有经验的人看。
  3. 最后一行是给你的建议系统会判断这是哪一类错误，告诉你下一步做什么。
最常见的错误意思怎么办
NameError 用到了还没定义的东西。 点「从头跑到这」，把前面的代码补跑一遍就好了。
ModuleNotFoundError 这段代码要用的工具包服务器上没装。 点「问助教」，或者跳过这一段——不是你的问题。
FileNotFoundError 找不到要读的数据文件。 多半也是前面的代码没跑。先「从头跑到这」。
其他看不懂的 —— 点「问助教」，代码和报错会一起发过去，它会解释。
如果按钮点了没反应

多半是执行环境没启动。这不是你能解决的，找管理员说一句「执行容器没起来」即可， 那边一条命令就能恢复。

8问助教

这是最实用的功能。任何一段代码旁边点「问助教」，右边会滑出对话面板， 而且问题已经替你写好了：

{{IMG:12-问助教预填|输入框里已经填好了这段代码、它的运行结果或报错，还有一句现成的问题。}}

预填的内容里包含三样东西：这是第几段代码、代码的完整内容、以及它刚才的运行结果或报错。 所以助教知道你在看什么，不用你再解释一遍。

  1. 可以直接按回车发送用现成的问题就行。
  2. 也可以先补一句自己的疑问比如在后面加上「这个参数改成 5 会怎样？」，一起发过去。
  3. 回答出来后可以接着追问它记得上文。
{{IMG:13-助教回答|助教的回答。它同时回答了代码的问题和「哪一章讲微调」这种需要翻遍全课才知道的问题。}}

助教能答到什么程度

如果这门课建过检索索引（第 4 节那个勾选项），助教回答时会去翻整门课的正文。 所以你可以问这类问题：

  • 「这门课哪一章讲微调？」
  • 「前面是不是提到过 tokenizer？在哪一节？」
  • 「这个概念和第 2 章讲的那个有什么区别？」

它会给出具体的章节，而不是含糊地说「课程后面会讲」。没建索引的课就答不了这类问题—— 可以随时回课程页补建。

除了在代码旁边问，你也可以直接点书页右下角的对话按钮，就这一页的内容自由提问。

9管理已有的课程

回到「课程」页，每张卡片右边有三个按钮：

按钮做什么注意
打开课本 跳到这门课的书页开始学。 —
建检索索引 / 重建索引 把整门课的正文做成可检索的资料库，让助教能翻遍全课回答。 要几分钟。课程内容更新过就重建一次。

想更新一门课（比如原课程作者更新了内容），做法是重新导入并勾上「覆盖」， 不用先删。重新导入之后记得再点一次「重建索引」。

11常见问题

我改坏了课程里的代码，会影响别人吗？

不会。你在代码框里的修改只在你自己的浏览器里，课程原文是只读的，改不动。 点「还原」就能回到原样。

点了运行，一直转圈不出结果

先看是不是要下载模型的那类代码（第一次会慢，几十秒很正常）。超过两三分钟还没动静， 刷新页面重试；还不行就是执行环境出问题了，找管理员。

为什么有的代码段没有「运行」按钮

只有 Python 代码能跑。课程里的命令行片段、配置文件片段这些只作展示，没有按钮。

助教说的不对怎么办

它会出错，尤其是没建检索索引的课，它可能凭印象回答。 遇到拿不准的，追问一句「这是课程里写的还是你推测的？」，或者去课本里核对原文。

我的对话记录会保存吗？

会。左边「最近」那一栏能看到之前的对话，点进去接着聊。

能自己导一门课吗？

能，就是第 4 节讲的。只要那门课在 GitHub 上有公开仓库、内容是 Markdown 文档或者 Jupyter 笔记本（.ipynb）就行。导进来试试，不合适删掉即可。

课本里图片显示不出来

有的课程把图片存在外部网站上，服务器访问不到就会裂开。这不影响正文和代码。

12名词表

手册里出现过的词，按第一次出现的顺序：

课程 / 课本 / 书
同一样东西的三种叫法。「课程」是从网上导进来的原始资料， 导进来之后在「书籍」里显示成一本可读的「课本」。
检索索引（也叫知识库）
把整门课的文字做成一份可以快速查找的资料库。有了它，助教回答时能翻遍全课， 告诉你某个内容在第几章讲过；没有它，助教只能凭自己知道的回答。
代码格 / 单元格（cell）
课本里一段可以单独运行的代码，界面上标着「第 N 格」。 这个说法来自 Jupyter 笔记本——那是数据分析和机器学习领域最常用的一种文档格式， 把讲解和可运行的代码交替排在一起。
Jupyter 笔记本（.ipynb 文件）
上面说的那种文档格式。很多公开课的练习就是用它写的。 导入课程时系统会自动认出来，把里面的每一格变成课本里可运行的代码段。
计算状态
代码跑过之后留在内存里的东西——读进来的数据、算出来的结果、定义的变量。 同一页的代码共享同一份，所以后面的代码能用前面的成果。「重置」就是把它清空。
模型
助教背后的人工智能。本系统用的是机房里自己跑的模型，你的提问不会发到外部网站。
仓库地址
GitHub 上一个项目的网址，形如 https://github.com/用户名/项目名.git。 导入课程时要填的就是它。
