## 一、可行性阶段（2026-07-31，在做之前先验证机制）

那时还没写任何代码，目的是确认「长驻内核 + 容器隔离 + 本地模型驱动」这条路走得通。实验脚本当时放在 `~/nb-lab/`，现已清理，但结论与数据保留在这里。

### 实验 1：长驻内核能否保持状态、能否取回各类输出

用 `jupyter_client` 起一个 Python 内核，逐次提交代码：

```
[赋值]              0.22s -> (无输出)
[读上一格的变量]     0.01s -> result='42'                    ← 状态保持住了
[打印+表达式值]      0.01s -> stdout='hello from cell 3' | result='41'
[画图]              0.89s -> 图片×1 image/png:19020B         ← 图能拿到二进制
[报错]              0.07s -> 错误 ZeroDivisionError: division by zero
[报错之后再读变量]   0.01s -> result='82'                    ← 报错没有打断内核
```

**结论**：四类输出都能结构化取回，报错不会杀死内核——这正是教学场景需要的，学生写错了改一改接着跑。

### 实验 2：真实课程 notebook 能否整份跑通

ML-For-Beginners 线性回归课的答案本，20 个代码格，用到 pandas、numpy、matplotlib、scikit-learn：

```

√ 第 8格  0.09s  pie_pumpkins = ...   stdout='-0.2669192282197318' | 图片×1

                 stdout='Mean error: 2.73 (17.0%)' | 图片×1
```

**顺带发现一个实现约束**：notebook 读数据用的是 `'../../data/US-pumpkins.csv'` 这样的相对路径，**执行时的工作目录必须是 notebook 所在目录**。

### 实验 3：容器隔离边界

内核关进容器（官方科学计算镜像，4 GB 内存、2 核、256 进程上限），只把课程目录以只读方式、工作目录以可写方式挂进去：

```
[导入科学计算库并赋值]              1.17s -> (无输出)
[读上一格的变量]                    0.05s -> result='49'                  ← 状态保持
[画图]                             0.27s -> 图片×1（base64 23796 字符）
[能否看到宿主上 DeepTutor 的配置文件] 0.05s -> result='False'             ← 看不见
[只读挂载的课程目录]                 0.05s -> result="['2-Regression']"
[写只读挂载]                        0.15s -> OSError: Read-only file system ← 写不了
[写可写工作目录]                     0.01s -> result='2'                  ← 能写
[运行身份]                          0.05s -> 'uid=1000(jovyan)'           ← 非 root
```

同一份课程 notebook 在容器里重跑：**19 格全部通过，总耗时 3.6 秒**，比宿主机上慢约 1.5 秒。

**结论**：隔离达到预期，开销可以接受。

### 实验 4：本地模型能否胜任 notebook 助教的调度

给模型三个工具（列出单元格、读某格源码、执行某格），提一个需要连续动作的问题：「第 8 格算出来的相关系数是多少？说明南瓜价格和第几天的关系强不强？这一格画的是什么图？」

```
第1轮 list_cells()   → 先看看总共有哪些格
第2轮 read_cell(8)   → 读第 8 格源码，发现它依赖前面的变量
第3轮 run_cell(1)    → 先跑第 1 格（导入并读数据）
第4轮 run_cell(2)    → 再跑第 2 格（数据清洗）
第5轮 run_cell(8)    → 这时才跑第 8 格
第6轮 给出最终回答     总耗时 16.3 秒

回答要点核对：
  [√] 提到了相关系数数值 -0.26
  [√] 判断为弱相关/负相关
  [√] 识别出散点图
```

**结论**：它自己推断出了单元格之间的依赖关系，没有直接去跑第 8 格撞上变量未定义。用本地模型（116 上的 qwen3.6-27B）做 notebook 助教是可行的，不必依赖外部大模型服务。

### 测算：ipynb 转教学 Markdown 的体积

```
ipynb 原文 115 KB，其中内嵌图片的 base64 占 84 KB（73%）
转成教学 markdown 后 11 KB，压缩到原来的 9%
```

**结论**：七成体积是检索时毫无意义的噪声，导入前必须转换，而不是放宽扩展名白名单了事。

### 文件类型判定

```
lesson.ipynb   知识库收录扩展名? False  分类=unknown  上传白名单? False
README.md      知识库收录扩展名? True   分类=text     上传白名单? True
notebook.py    知识库收录扩展名? True   分类=text     上传白名单? False
data.csv       知识库收录扩展名? True   分类=text     上传白名单? True
```

**结论**：`.ipynb` 既不在上传接口白名单也不在知识库收录集合里，目录扫描会直接跳过。
