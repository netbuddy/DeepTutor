# 从零实现一个 AI Agent（Go 版）

一步步实现一个能干活的 agent：能对话、能调工具、能读写文件、能跨进程续上会话、
上下文满了会自己压缩。

参照 [pi-agent-core](https://github.com/earendil-works/pi) 的实际结构，按渐进路径重排——
**每一章解决一个具体问题，每一章结束时手里的东西都能跑**。

这门课不是把 pi 的三万行翻译一遍。那里面大部分代码在处理各家模型供应商的差异，
对理解 agent 原理没有帮助。目标是：**读完这门课，再去看 pi 的源码能看懂**。

**页面上的 Go 代码怎么跑**：Go 是编译型语言，没有像 Python 那样的长驻内核。
一页里的每一格代码是模块里的一个文件，点「运行」时会把这一页到当前格为止的所有文件
凑齐一起编译。每格开头那行 `// file: xxx.go` 固定了它写进哪个文件，反复运行不会积出
重复定义。还没有 `main` 函数的章节，点运行会做类型检查。

另有一门同样大纲的 [Python 版](../python/)，两边对照着看，能看清同一个机制在两种语言里
的不同写法。
