# 从零实现一个 AI Agent（Python 版）

一步步实现一个能干活的 agent：能对话、能调工具、能读写文件、能跨进程续上会话、
上下文满了会自己压缩。

参照 [pi-agent-core](https://github.com/earendil-works/pi) 的实际结构，按渐进路径重排——
**每一章解决一个具体问题，每一章结束时手里的东西都能跑**。

这门课不是把 pi 的三万行翻译一遍。那里面大部分代码在处理各家模型供应商的差异，
对理解 agent 原理没有帮助。目标是：**读完这门课，再去看 pi 的源码能看懂**。

页面上的代码可以直接改、直接跑。同一页的代码格共享一个长驻的 Python 环境，
前面定义的东西后面直接能用；换一页就是全新的开始。

另有一门同样大纲的 [Go 版](../go/)，两边对照着看，能看清同一个机制在两种语言里的不同写法。
