# 消息与内容块

上一章的消息长这样：

```python
{"role": "user", "content": "北京现在几点？"}
```

`content` 是个字符串。这在只有纯文本时够用，但助手的一条回复里**可能同时有文字和
若干个工具调用**——

> 「我先查一下时间。」+ `get_time(city="北京")` + `get_weather(city="北京")`

一个字符串装不下这三样东西。所以真实的 agent 框架都把 `content` 做成**一个列表**，
列表里是若干**内容块**（content block），每块有自己的类型。pi 是这么做的，Anthropic 和
OpenAI 的接口也都是这么做的。

## 三种块就够了

| 块类型 | 谁产生 | 装什么 |
|---|---|---|
| `text` | 用户或模型 | 一段文字 |
| `tool_use` | 模型 | 「我要调这个工具，参数是这些」，带一个调用编号 |
| `tool_result` | 我们的代码 | 工具执行完的结果，用调用编号对上是哪一次调用 |

**调用编号（`id`）是关键。** 一轮里模型可能同时要求调三个工具，结果回填时必须能对上
是哪个结果配哪个调用，靠的就是这个编号。

## 定义出来

```python
from __future__ import annotations
from dataclasses import dataclass, field
from typing import Any, Literal
import json
import uuid


def new_id(prefix: str) -> str:
    """给块和消息发一个短编号。真实实现里这个编号还要在存储里做主键。"""
    return f"{prefix}_{uuid.uuid4().hex[:12]}"


@dataclass
class TextBlock:
    text: str
    type: Literal["text"] = "text"


@dataclass
class ToolUseBlock:
    name: str                                  # 工具名
    args: dict[str, Any]                       # 模型给的参数
    id: str = field(default_factory=lambda: new_id("call"))
    type: Literal["tool_use"] = "tool_use"


@dataclass
class ToolResultBlock:
    tool_use_id: str                           # 对应哪一次调用
    content: str                               # 工具的输出
    is_error: bool = False                     # 工具是抛错了还是正常返回
    type: Literal["tool_result"] = "tool_result"


Block = TextBlock | ToolUseBlock | ToolResultBlock


@dataclass
class Message:
    role: Literal["system", "user", "assistant", "tool"]
    content: list[Block]
    id: str = field(default_factory=lambda: new_id("msg"))

    def text(self) -> str:
        """把这条消息里所有文字块拼起来。日志和展示常要用。"""
        return "".join(b.text for b in self.content if isinstance(b, TextBlock))

    def tool_uses(self) -> list[ToolUseBlock]:
        return [b for b in self.content if isinstance(b, ToolUseBlock)]


print("三种块和消息类型定义好了")
```

## 用它表示上一章那轮对话

```python
history: list[Message] = [
    Message(role="user", content=[TextBlock(text="北京现在几点？")]),
]

# 模型的回复：一句话 + 一个工具调用，两个块并存
call = ToolUseBlock(name="get_time", args={"city": "北京"})
history.append(Message(
    role="assistant",
    content=[TextBlock(text="我查一下。"), call],
))

# 工具结果：用 tool_use_id 对上刚才那次调用
history.append(Message(
    role="tool",
    content=[ToolResultBlock(tool_use_id=call.id, content="14:32")],
))

history.append(Message(
    role="assistant",
    content=[TextBlock(text="北京现在是 14:32。")],
))

for m in history:
    kinds = "、".join(b.type for b in m.content)
    print(f"{m.role:10} 块：{kinds:24} 文字：{m.text() or '（无）'}")
```

跑出来能看到，第二条消息里 `text` 和 `tool_use` 两种块**并存在同一条消息里**——
这正是上一章那个字符串装不下的东西。

## 序列化：存下来、传出去

消息要能存进文件、发给模型，所以必须能变成 JSON 再变回来。dataclass 转字典很容易，
难点在**变回来的时候要知道每个块是什么类型**——靠的就是每个块里那个 `type` 字段。

```python
from dataclasses import asdict

_BLOCK_TYPES = {
    "text": TextBlock,
    "tool_use": ToolUseBlock,
    "tool_result": ToolResultBlock,
}


def message_to_dict(m: Message) -> dict:
    return {"id": m.id, "role": m.role, "content": [asdict(b) for b in m.content]}


def message_from_dict(d: dict) -> Message:
    blocks = []
    for raw in d["content"]:
        raw = dict(raw)
        kind = raw.pop("type")
        cls = _BLOCK_TYPES.get(kind)
        if cls is None:
            # 遇到不认识的块类型就跳过，而不是整条消息读不出来。
            # 存储格式会演进，旧代码读新数据是常态。
            continue
        blocks.append(cls(**raw))
    return Message(id=d["id"], role=d["role"], content=blocks)


# 存一遍再读回来，确认前后一致
raw = [message_to_dict(m) for m in history]
restored = [message_from_dict(d) for d in raw]

print(json.dumps(raw[1], ensure_ascii=False, indent=2))
print()
print("往返之后还一致吗：", [message_to_dict(m) for m in restored] == raw)
```

## 为什么不用字符串拼

有人会想：直接把工具调用写成 `"[调用 get_time(city=北京)]"` 塞进字符串不行吗？

不行，三个原因：

1. **要能精确对上。** 一轮三个工具调用，结果回填时靠编号配对，字符串里没有编号。
2. **要能发给模型。** 模型接口要的就是结构化的工具调用字段，你最终还得解析回来。
3. **要能被程序检查。** 「这一轮模型调了哪些工具」这种问题，遍历块是一行代码，
   解析字符串是一堆正则。

## 本章小结

- 一条消息的 `content` 是**一个块列表**，不是字符串。
- 三种块够用：文字、工具调用、工具结果。
- **工具调用要带编号**，结果靠编号对上。
- 序列化时每个块自带 `type` 字段，反序列化时靠它还原类型；**遇到不认识的类型要跳过
  而不是报错**，因为存储格式会演进。
