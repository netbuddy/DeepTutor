# 脚本化模型

第 1 章那个假模型是写死的：看到工具结果就回答，否则要求调工具。它只能演一出戏。

这一章把它做成**能按剧本演的假模型**：给它一份剧本，它就照着吐。有了这个东西，
整条链路可以在完全不联网的情况下跑，而且**每次输出都一模一样**——这是写测试的前提，
也是这门课前八章都不需要联网的原因。

pi 里这个东西叫 `ScriptedModel`，几乎所有 agent 框架都有对应物。

## 模型接口长什么样

在定义假模型之前，得先定义**真模型和假模型共同的接口**。这个接口定得好不好，决定了
第 8 章换成真模型时要改多少代码——理想情况是一行不改。

一次模型调用的输入输出：

- **输入**：消息历史、可用的工具声明
- **输出**：一串增量事件（文字一段段来、工具调用一个个来），最后是一条完整消息

```python
from __future__ import annotations
from dataclasses import dataclass, field
from typing import Any, Iterator, Literal, Protocol
import uuid

def new_id(prefix: str) -> str:
    return f"{prefix}_{uuid.uuid4().hex[:12]}"

@dataclass
class TextBlock:
    text: str
    type: Literal["text"] = "text"

@dataclass
class ToolUseBlock:
    name: str
    args: dict[str, Any]
    id: str = field(default_factory=lambda: new_id("call"))
    type: Literal["tool_use"] = "tool_use"

@dataclass
class ToolResultBlock:
    tool_use_id: str
    content: str
    is_error: bool = False
    type: Literal["tool_result"] = "tool_result"

@dataclass
class Message:
    role: Literal["system", "user", "assistant", "tool"]
    content: list[Any]
    id: str = field(default_factory=lambda: new_id("msg"))
    def text(self) -> str:
        return "".join(b.text for b in self.content if isinstance(b, TextBlock))
    def tool_uses(self) -> list[ToolUseBlock]:
        return [b for b in self.content if isinstance(b, ToolUseBlock)]


# ── 模型接口 ──────────────────────────────────────────────────────────

@dataclass
class Delta:
    """模型吐出来的一小段。真模型的流式响应最终都会被翻译成这个。"""
    kind: Literal["text", "tool_use"]
    text: str = ""                      # kind == "text" 时有值
    tool: ToolUseBlock | None = None    # kind == "tool_use" 时有值


class Model(Protocol):
    """所有模型都长这样。假模型和真模型的唯一区别是这个方法怎么实现。

    用 Protocol 而不是抽象基类：调用方只关心"有没有这个方法"，
    不要求实现方继承什么——第 6 章那个真模型适配器不必知道这个协议存在。
    """

    def stream(self, messages: list[Message], tools: list[dict]) -> Iterator[Delta]:
        ...


print("模型接口定义好了")
```

## 剧本怎么写

剧本是一个列表，每一项是模型的一次回复。一次回复可以是纯文字，也可以带工具调用。

```python
@dataclass
class ScriptedTurn:
    """剧本里的一幕：模型这一次要说什么、要调什么工具。"""
    text: str = ""
    tool_calls: list[tuple[str, dict]] = field(default_factory=list)   # [(工具名, 参数), …]


class ScriptedModel:
    """按剧本演的假模型。

    它完全不看输入的消息历史——这是有意的。假模型的价值在于**输出可预测**，
    一旦让它根据历史做判断，就又变成一个需要单独测试的东西了。
    需要按历史分叉的场景，写两份剧本分别跑。
    """

    def __init__(self, script: list[ScriptedTurn], chunk_size: int = 4) -> None:
        self.script = script
        self.chunk_size = chunk_size          # 文字每次吐几个字，模拟真实分块
        self.call_count = 0                   # 演到第几幕了

    def stream(self, messages: list[Message], tools: list[dict]) -> Iterator[Delta]:
        if self.call_count >= len(self.script):
            raise RuntimeError(
                f"剧本只有 {len(self.script)} 幕，但模型被调用了第 {self.call_count + 1} 次。"
                "多半是主循环没有正常结束——去看看退出条件。"
            )
        turn = self.script[self.call_count]
        self.call_count += 1

        for i in range(0, len(turn.text), self.chunk_size):
            yield Delta(kind="text", text=turn.text[i : i + self.chunk_size])

        for name, args in turn.tool_calls:
            yield Delta(kind="tool_use", tool=ToolUseBlock(name=name, args=args))


def collect(deltas: Iterator[Delta]) -> Message:
    """把一串增量攒成一条完整的助手消息。真模型那边也用这个函数。"""
    text_parts: list[str] = []
    blocks: list[Any] = []
    for d in deltas:
        if d.kind == "text":
            text_parts.append(d.text)
        elif d.tool is not None:
            if text_parts:                     # 文字块要排在它后面的工具调用之前
                blocks.append(TextBlock(text="".join(text_parts)))
                text_parts = []
            blocks.append(d.tool)
    if text_parts:
        blocks.append(TextBlock(text="".join(text_parts)))
    return Message(role="assistant", content=blocks)


print("脚本化模型与增量收集器就绪")
```

## 演一遍

```python
script = [
    ScriptedTurn(text="我查一下时间。", tool_calls=[("get_time", {"city": "北京"})]),
    ScriptedTurn(text="北京现在是下午 2 点 32 分。"),
]

model = ScriptedModel(script)

print("── 第一次调用（模型要求调工具）──")
for d in model.stream([], []):
    if d.kind == "text":
        print(f"  文字增量：{d.text!r}")
    else:
        print(f"  工具调用：{d.tool.name}({d.tool.args})  编号 {d.tool.id}")

print("\n── 第二次调用（模型给最终回答）──")
msg = collect(model.stream([], []))
print("  收集成的消息：", [b.type for b in msg.content])
print("  文字：", msg.text())
```

## 确定性：跑两次结果一样

这是脚本化模型最重要的性质。真模型每次回答都不同，没法写断言；假模型可以。

```python
def run_once() -> list[str]:
    m = ScriptedModel(script)
    out = []
    for _ in range(2):
        msg = collect(m.stream([], []))
        out.append(msg.text())
        out.extend(f"{t.name}{t.args}" for t in msg.tool_uses())
    return out

first, second = run_once(), run_once()
print("第一次：", first)
print("第二次：", second)
print("两次完全一致：", first == second)
```

## 剧本用完了会明确报错

新手最常见的 bug 是主循环不退出——模型明明已经给了最终回答，循环还在继续问。
脚本化模型让这种 bug **立刻暴露**，而不是悄悄多转几圈：

```python
m = ScriptedModel([ScriptedTurn(text="只有一幕")])
collect(m.stream([], []))          # 第一次，正常
try:
    collect(m.stream([], []))      # 第二次，剧本没了
except RuntimeError as exc:
    print("报错了，而且说清了原因：")
    print(" ", exc)
```

换成真模型，这里只会多花几秒钱、多一条无意义的回复，你可能根本发现不了。

## 第 1 章那个流程，现在用真接口跑一遍

```python
def get_time(city: str) -> str:
    return "14:32"

TOOLS = {"get_time": get_time}

def run(user_text: str, model: Model, max_rounds: int = 5) -> str:
    history = [Message(role="user", content=[TextBlock(text=user_text)])]
    print(f"用户：{user_text}\n")

    for round_no in range(1, max_rounds + 1):
        reply = collect(model.stream(history, []))
        history.append(reply)

        if reply.text():
            print(f"模型：{reply.text()}")

        calls = reply.tool_uses()
        if not calls:                        # 没有工具调用了，这一轮结束
            return reply.text()

        results = []
        for call in calls:
            output = TOOLS[call.name](**call.args)
            print(f"工具：{call.name} → {output}")
            results.append(ToolResultBlock(tool_use_id=call.id, content=output))
        history.append(Message(role="tool", content=results))

    return "循环次数用完了"


answer = run("北京现在几点？", ScriptedModel(script))
print("\n最终答案：", answer)
```

对比第 1 章那段桩代码：**流程完全一样，但每个部件都换成了正经的类型**。
第 8 章我们把 `ScriptedModel` 换成真模型时，`run` 这个函数一个字都不用改。

## 本章小结

- 先定**模型接口**，再实现假模型和真模型，这样换实现时上层不用改。
- 接口的输出是**增量流**（文字一段段、工具调用一个个），因为真模型就是这么吐的。
- 脚本化模型的价值是**确定性**：能写断言、能复现、不花钱、不联网。
- **剧本用完要明确报错**——它能立刻暴露主循环不退出这类 bug。
- 假模型**不应该看历史做判断**，否则它自己就变成需要测试的东西了。

第一部分到这里结束。我们手上有了：结构化的消息、事件流、能落盘的历史、可预测的假模型。
